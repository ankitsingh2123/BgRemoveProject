# 🖼️ Background Remover - MERN Stack Project

**Live App**: [https://bg-remove-project.vercel.app/](https://bg-remove-project.vercel.app/)

This is a full-stack application built with the **MERN stack** (MongoDB, Express, React, Node.js) that allows users to upload an image and remove its background using an AI-based API.

---

## ✨ Features

- Upload image files
- Preview original and background-removed images
- Remove background using AI (like `remove.bg` or `rembg`)
- Download the processed image

---

## 🚀 Tech Stack

- **Frontend:** React, JavaScript, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (optional for storing data)
- **AI Tool:** External API or Python-based background removal

---

## 🔧 Getting Started

### Prerequisites

- Node.js and npm installed
- MongoDB running (if used)
- API key (if using a third-party background remover like remove.bg)
